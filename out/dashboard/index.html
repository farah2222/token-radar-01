How the value is worked out

Implied value = max(1, round(TVL × category multiple × growth × maturity × breadth))

  • Category multiple — median Mcap/TVL of the live-token protocols in the same category (at least 3 needed); otherwise the global median across all 119 live-token protocols. Clamped to 0.05–1.50.
  • Growth — 1 + clamp(7-day change, −60, 120) / 100 × 0.5. A missing 7-day change counts as 0.
  • Maturity — 0.6 + min(age in days, 1095) / 1095 × 0.4. Age is the snapshot date minus the day DefiLlama first tracked the protocol; unknown counts as 365 days.
  • Breadth — 1 + 0.04 × min(chains − 1, 5).
  • Likely rank A–B — the same calculation with the category's 25th and 75th percentile multiples instead of the median, showing the ranks those values would take. It is the comparables' own spread, not a guess.
